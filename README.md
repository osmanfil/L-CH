# 🔮 Lich AI

Lich AI, kullanıcıların kendi OpenAI API anahtarlarını (API Key) kullanarak yapay zeka modelleriyle özgürce, esnek ve güvenli bir şekilde iletişim kurmasını sağlayan modern bir web uygulamasıdır. 

Proje, şık bir Koyu Tema (Dark Mode) arayüzüne sahip olup, tamamen kullanıcı dostu bir deneyim sunmak amacıyla tasarlanmıştır.

---

## ✨ Özellikler

*   🔑 **Kişisel API Anahtarı Desteği:** Sunucu maliyetleri veya sınırlandırmalara takılmadan, kendi API anahtarınızla tam kontrol.
*   🧠 **Gelişmiş Model Seçenekleri:** `gpt-4o`, `gpt-4-turbo` ve `gpt-3.5-turbo` modelleri arasında anında geçiş imkanı.
*   🎨 **Modern Koyu Tema:** Gözü yormayan, mor ve siyah tonlarında özelleştirilmiş şık arayüz tasarımı.
*   💾 **Sohbet Hafızası:** Sekme açık kaldığı sürece geçmiş mesajları hatırlayan akıllı session yapısı.
*   🔒 **Güvenli Altyapı:** API anahtarınız hiçbir sunucuda saklanmaz, doğrudan tarayıcınız ve OpenAI altyapısı arasında çalışır.

---

## 🛠️ Kullanılan Teknolojiler

Bu proje, modern web teknolojileri ve Python kütüphanelerinin güçlü bir kombinasyonu ile geliştirilmiştir:

*   **HTML5 & CSS3:** Özelleştirilmiş arayüz bileşenleri ve Koyu Tema tasarımı.
*   **JavaScript:** Dinamik sayfa hareketleri ve kullanıcı etkileşimleri.
*   **Python (Streamlit):** Web arayüzünün sunucu ve API entegrasyonu ile canlıya taşınması.
*   **OpenAI API:** Yapay zeka zekasının arkasındaki motor.
